A tiny Node 22 (stdlib-only) program that writes one sentence — an alien tourist's one-star review of Earth with a real compliment about the food — to `/output/entry.txt` and prints it to stdout.

## Run

```sh
node main.ts
```

## The line

> One star. The locals queue for hours to stare at a glowing rectangle, but the tacos are so good I am delaying the invasion.
